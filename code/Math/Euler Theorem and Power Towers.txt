Euler's theorem: if gcd(a, m) = 1, then a^phi(m) = 1 (mod m).
Therefore a^b mod m = a^(b mod phi(m)) mod m only when gcd(a,m)=1.

For a power tower such as a^(b^c) mod m:
1. If gcd(a,m)=1, reduce the exponent modulo phi(m), recursively.
2. If gcd(a,m) != 1, blindly reducing the exponent can be wrong.
   Use a proven non-coprime tower method, or split prime powers and use CRT.
3. Stop the recursion once the modulus becomes 1. Handle 0^0 according to
   the problem statement.

Useful totient facts:
- phi(p^k) = p^k - p^(k-1) for prime p.
- If gcd(m,n)=1, phi(m*n) = phi(m)*phi(n).
- phi(n) = n * product over distinct p|n of (1 - 1/p).

This note is a safe reduction guide; it is not a complete arbitrary-tower solver.
